每一块是一层：横向范围 = 哪段亮度属于这层，块的高矮 = 这层的高度。上下拖块改高度，拖分界线改范围。

这种方式下「中间调 / 对比」不参与；③ 的黄线白线仍决定各层对应的亮度范围。
